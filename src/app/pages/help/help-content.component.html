词汇

筛选列表

有两种筛选，它们同时生效：

  • 自由文本框：把整段输入当成一个短语，在每行的编号、英文单词或中文释义里查找，忽略大小写，是简单的「包含」判断；用输入法组词时不会中途刷新表格。

对话框里左边是条件树，右边编辑当前选中的节点：

节点可以设置什么

练习模式

每个项目都会先打开选项对话框，并且记住你上次的选择。取材规则始终是：先取勾选的行（全部，随机顺序）；没有勾选就用可见行，并以你填的数量为上限。

  • 复习——卡片模式：先看英文，播放发音，再显示释义；释义（词性 + 中文意思）和双语例句以表格显示在下方，宽度与工具栏一致。选项：数量、禁用语音、隐藏讲解（两者不能同时关闭，否则无从学起）。所有操作都集中在一行工具栏里：进度条和队列位置（如 3 / 20）、复习标签、当前词的 1–5 评分按钮，以及六个图标按钮（自动播放进行中会多出第七个「停止」按钮）——自动播放设置（调节图标：每个条目的秒数、自动播放是否按随机顺序翻阅——只影响自动播放的浏览路线，不会改变队列本身——以及浏览器朗读的例句数量 0–10）、播放/暂停（自动播放有三态——默认停止、播放中、已暂停：播放从第一个词开始，同一按钮可在当前词暂停并静音所有声音，再按一次继续），停止（结束自动循环，回到手动翻阅；仅在播放中或已暂停时显示）、重新朗读（重放当前单词及其例句）、上一个 / 下一个 / 退出。每个条目是单词加朗读的例句；间隔时间是条目之间的秒数，每次翻页都会等当前条目的朗读完整结束才继续。进度按本次播放的位置计算——开启随机顺序时，进度条跟着随机翻阅顺序走，一整轮播完就显示 100%（而不是最后一个词在队列里的随机位置）。运行中修改间隔会立即生效（当前条目重新计时）；朗读数量从下一个条目起生效；随机顺序在下次开始播放时生效。正在朗读的例句会在表格中高亮并保持可见。离开页面时自动播放会停止。
  • 练习纸——可打印的版本，见下一小节。
  • 拼写——听着发音逐字母输入。字母对了就显示并伴随提示音；错了会响提示音并把该词标记为错误；退格重新隐藏最后一个字母。提示按钮显示当前字母（代价是该词记为错误），下一个词直接跳过。队列走完会给出得分和逐词的对错列表。

评分与发音

每行最后一列是 1–5 的评分，按「你 + 这个文件 + 这个单词」保存到你的账号下。评分是你标记「这个词老出错」的方式：它既是评分筛选条件的数据来源，也会带进复习队列。再次点击当前分值不会取消——一个词只有「已评」和「未评」两种状态，未评在筛选时按 0 计算。

发音优先使用已录好的音频，没有录音时改用浏览器自带的语音引擎，因此这两者都不需要邀请码。

打印

「练习 ▾」→「打印」打开选项对话框。关键选项是等级，它决定每篇课文被挖掉多少：简单挖去约两成字符，中等一半，困难八成，全部则整篇隐去（正文变成一份供听写的答案）。每行一个答案会把还原的每个字符组单独排一行，学生直接在卷子上书写时正是你想要的效果。

输出的打印页与词汇练习纸同一套：先是题目行，分页之后是答案页。

两处需要如实说明：本页面的背诵选项目前只会打开选项对话框，尚不会开始一场背诵会话；打印录入日期与执行日期选项会被记录，但目前不影响打印出来的内容。

习惯打卡

习惯就是在一段时间里反复记录的事，而这段时间需要一个结论：这周我达标了吗？每条习惯包含一个周期（每日、每周、每月或整段期间）、开始日期和可选的结束日期、若干用来记录的条目（每个条目有自己的属性），以及判分标准——它决定哪天算成功、整周期算不算通过。

从模板创建习惯

新建习惯打开一个五步向导：模板 → 基本信息 → 条目 → 目标 → 预览。

  • 选一个模板，或选自定义从空白开始。
  • 模板会填入名称、周期、条目与属性、以及目标。所有内容都可以继续编辑：改条目名、换属性类型、加第五个项目、设自己的目标。模板不会把习惯锁死。
  • 条目这一步管理你要记录的内容。属性可以是是/否、数字或列表（自由填写的条目，可选择按天或按周期去重）。
  • 目标这一步就是判分标准。根判分标准不同类型，你设置的是周期目标（"这周要有这么多天成功"）或阈值（"这周累计这么多公里"）。
  • 预览会用你大概会记录的打卡数据模拟一整个周期，让你在保存之前就看到进度条和结论。特殊配置下模拟结果只是近似，真实计算在服务器上进行。

已经改过内容时重新选模板会先要求确认：它会替换你现有的条目和判分标准。

打卡

卡片上的打卡（或习惯详情页上的同名按钮）打开一次记录。每个条目是一个独立面板，控件取决于属性类型：

  • 是/否——勾上即刻保存。同一属性同一条目同一天只有一个值，当天再勾一次会覆盖前一次。
  • 数字——填一个量，每次提交都会累加到当天和整期的合计里，所以三次短跑的里程会相加；同一条目一天可以记录多次。
  • 列表——一行一条。条目按顺序追加；若该属性标记为按天唯一，当天已记录过的内容会被拒绝。被拒绝的条目会让该条目本次的记录整条失效，并指名是哪几行；同一次会话里的其它条目照常保存，提示会告诉你哪些失败了。

关于日期，这也是最容易让人意外的地方：

  • 新建的打卡可以记在今天或这段期间内更早的日子，绝不能记到未来，也不能早于开始日期。对话框在日期选择器下方写明了可打卡的区间。
  • 一次会话只要已经记录了内容，日期就锁定：之后勾选的条目仍按你开始时的日期盖章，因为悄悄挪动会让它们对不上号。要记另一天，请关掉对话框再打开一次。
  • 已保存的打卡日期永久不变。要挪动一条记录，请在打卡历史里删掉它，再打卡到正确的日子。数值则随时可以修改——即使期间已结束、习惯已停用也一样——而当天、当周期和整份历史都由保存的打卡重新算出，所以一处修正会同步反映到所有地方。
  • 日期按服务器的时区计算，跨时区旅行时，程序里的"今天"可能与你的本地零点不同。

进度、日历与编辑

习惯卡片显示本周期的进度条、根目标的 当前 / 目标，周期达成时会有一个红色的达标标记；每日习惯还会显示今天自己的数值。编辑会在同一个习惯上重新打开向导。每张卡片的菜单里有分享、停用和删除。

日历页按月、按周或按天铺开打卡记录，让你一眼看出一个月的形状，而不必去读一根根进度条。

停用会把习惯永久设为只读——历史保留，不能再打卡，也无法重新启用，因此它会要求确认。删除会连同条目、判分标准和全部打卡历史一起移除；一旦该习惯已分享给别人，删除会被拒绝。

分享习惯

卡片菜单里的分享…可以邀请指定用户（按显示名搜索；程序只能看到名字和一个 id，看不到邮箱）。邀请立即生效，也可以立即撤销。被邀请者得到的是待我共享页面上该习惯的只读视图：完整打卡历史都在，注明作者，但所有写入入口都去掉了——他不能打卡、编辑、分享或删除，也看不到你还把它分享给了谁。分享不转移所有权，同一个人重复邀请也不会产生第二条记录。

登录

邀请码，以及哪些功能需要它

盾牌图标打开一个填邀请码的小对话框。只有 AI 功能需要它——句子页面的"讲解"和与 AI 对话，以及公式页面生成的测验。上文介绍的一切都无需邀请码：词汇复习、拼写、听写、自己组卷的测验、练习纸、中文与知识库打印、整个习惯打卡。没有录音时发音改用浏览器语音引擎，因此也不额外收费。

语言

学习内容本身不会被翻译：单词文件里的中文栏和英文栏是文件自带的数据，不是界面文字。

你的数据去了哪里

评分、习惯、打卡和登录记录都按用户保存在学习 API 上，一切都不是匿名的：其他用户看不到它们，即使猜到编号也不行——唯一的例外是你主动分享出去的习惯。清理浏览器存储不会影响这些记录，它们存在服务器端，所以换一台机器登录，同一条习惯可以继续打卡。

  4. Narrow the list, then tick the rows you want to work on. Every exercise mode follows the same rule: if you have ticked rows, it uses exactly those; if you have ticked nothing, it uses the rows the filter leaves visible.
  5. Start a session from the Exercises menu — review, spell, dictate, quiz or print.

Each section below describes one page. The habit tracker is at the end, together with the twelve ready-made templates.

Vocabulary

Word lists with an English side and a Chinese side, one file per unit or word book. Everything here is also what the Chinese and Knowledge Bank pages do — only the fields differ.

Filter the list

Two things filter the table, and they combine:

  • The free-text box matches one phrase anywhere in the row's id, English word or Chinese meaning. It is a plain "contains" test, case-insensitive, and it does not restart the table while you are still composing characters with an input method.
  • Filter ▾ opens the condition editor. The menu's first item is labelled New when you have no filter and shows a summary of the current one otherwise; Clear removes the condition tree (it leaves the free-text box alone).

Inside the dialog, the left pane is the tree and the right pane edits whichever node you select:

NodeWhat you can set
ConditionA property, an operator and a value. Vocabulary offers Word, Chinese and Rating. Text properties support starts with, contains, equal, ends with and is phrase (matches a multi-word entry). Rating (0–5) supports ≥, >, =, ≤, < and between.
GroupWhether its members are joined by AND or OR, and which rows and nested groups belong to it. A group needs at least two members.

Use the three buttons above the tree to add a condition, add a group, or delete the selected node. The line at the bottom shows the whole expression as the app reads it, for example word contains app AND (chinese contains 派 OR rating >= 3). Submit is blocked while a value is missing or a group has fewer than two members; Cancel keeps the previous filter untouched.

Filtering never deletes anything — it only decides which rows are on screen, and that set is what the next exercise or worksheet will draw from.

Select the rows you want

Selection ▾ offers four ways in:

  • Select Randomly — enter a count, get that many rows picked from the visible ones in random order.
  • Select Sequentially — a count plus an offset, i.e. "take 20 rows starting at row 40" of the currently sorted, visible list.
  • Select by Words — paste a list separated by commas, spaces or new lines; matching rows are ticked and phrases like apple pie survive intact. Nothing is selected if none of the words match, so a bad paste never wipes a good selection.
  • Clear Selection.

The header checkbox ticks or clears every row currently visible, and sorting or paging keeps your selection.

Exercises

Every item opens an options dialog first; it remembers what you chose last time. The queue rule is always: ticked rows first (all of them, shuffled), otherwise the visible rows capped by the count you entered.

  • Review — flashcard mode: the English word, then play its audio and reveal the meaning; the explanation (part of speech + Chinese sense) and bilingual example sentences appear as two tables below, as wide as the toolbar. Options: count, Disable Voice, Hide Explanation (the two cannot both be off, or there would be nothing to learn from). Everything you touch sits in one toolbar: the progress bar with the position in the queue (e.g. 3 / 20), the Review label, the 1–5 rating buttons for the current word, and six icon buttons (a seventh, Stop, appears while auto play is on) — Auto Play settings (tune: seconds per item, whether auto play visits the words in a random order — that only changes the auto-play walk, never the list or manual browsing — and how many example sentences (0–10) the browser reads aloud), Play/Pause (Auto Play has three states — stopped by default, playing, paused: play starts from the first word, the same button pauses on the current word silencing all audio, pressing again resumes it), Stop (ends the cycle and leaves you browsing manually; only visible while playing or paused), Re-read (plays the current word and its sentences again), previous / next / quit. Each item is the word plus its read sentences; the interval is the seconds between items, and a tick always waits for the current item's reading to finish before advancing. The progress counts your place in the current run — with random order on, the bar tracks the shuffle, so finishing the whole run shows 100% (not the random queue slot the last word happened to sit in). Changing the interval during a run applies immediately (the item on screen is re-timed); the sentence count takes effect from the next item, and the random order the next time you start. The sentence being read is highlighted in the table and kept on screen. Leaving the page stops auto play.
  • Worksheet — the printable form, see below.
  • Spelling — type the word letter by letter while it is spoken. A correct letter reveals with a click; a wrong one is beeped and marks the word incorrect; Backspace hides the last letter again. The Hint button reveals the current letter (at the cost of marking the word incorrect) and Next Word skips. When the queue runs out you get a score and a per-word list.
  • Dictation — fully automatic: a word is spoken every five seconds, you write it down, and the answer list appears at the end.
  • Quiz — single-choice questions in the direction you pick, English→Chinese or Chinese→English. Four options come from the rows currently visible, so filtering to a unit makes the quiz about that unit. Answer by clicking or with 1–4 / A–D; Enter or → goes on, ← comes back to revisit. Questions that cannot gather three distinct alternatives are skipped.

Print a worksheet

  1. Tick rows or set a filter (otherwise all visible rows are used).
  2. Exercises ▾ → Worksheet, then choose: count, a sub-title printed under the heading, Print First Letter (each blank starts with its first letter) and Uniform Blank Length with its width, which hides how long each word is.
  3. Confirm and the app opens the print sheet: numbered lines of 1. <meaning> f________, then a page break and the answer key.
  4. Press Print at the top right. Only the sheet itself goes to the paper — the navigation bar, the counters and the buttons do not.

One caution: the sheet is assembled in memory. If you reload that page it disappears and sends you back to the list, so print or save to PDF before you navigate away.

Ratings and audio

The last column of every row is a 1–5 rating, saved to your account for that word in that file. Ratings are how you mark "I keep getting this one wrong": they drive the Rating filter condition, and they travel with you to the review queue. Clicking the active value again does nothing — a word is either rated or unrated, and unrated counts as zero when you filter.

Pronunciation comes from recorded audio where the app has it and falls back to your browser's own speech voices otherwise, so nothing needs an invitation code.

Chinese

Classical and modern Chinese reading material: each row is a text with its subject, author, source and content. The mechanics are the same as Vocabulary — file selector, free text, Filter ▾, Selection ▾ — with these fields instead:

  • Subject, Author and Content filter as text (starts with / contains / equal / ends with).
  • Rating works exactly like the vocabulary one.
  • The free-text box searches id, subject, author, content and source.
  • Selection ▾ has Select All Visible instead of Select by Words.

Print

Exercises ▾ → Print opens the options dialog. The important choice is Level, which decides how much of each text is blanked out: Easy hides about a fifth of the characters, Medium a half, Hard four fifths, and Full hides everything (the text becomes an answer key you dictate from). One Answer per Line puts each restored character group on its own line in the key, which is what you want when students write on the sheet itself.

The output is the same printable sheet as the vocabulary worksheet: prompt lines first, a page break, then the answer key.

Two honest notes for this page: the Recite item currently opens its options dialog but does not start a session, and Print Entry Date / Exec. Date Option are collected but do not change the printed sheet yet.

Knowledge Bank

Questions rather than words: each row carries a type (single choice, fill in the blank, and so on), a difficulty, an estimated time, tags, the question itself, its answer, optional hints and extra material.

Filter and select

  • The free-text box here is multi-term: separate words with spaces and every one of them must appear somewhere in the row — in the question, the options, the answer, a hint, the extra info or a sub-item. A row matches only if all your terms match.
  • Filter ▾ offers ID (text operators), Type (tick any of the question types; several ticks mean "this type OR that type"), Tags (text operators) and Rating.
  • Selection ▾ adds Select by ID: paste a list of question numbers, and the rows that exist in the current file are ticked. Select All Visible and Clear Selection are there as well.

Browse a question

Click a row's ID button to open the exercise view, or the icon in the Extra Info column to see only that material. Both screens have previous / next / back-to-list on the toolbar, and the exercise view adds Toggle Answer and Toggle Hint of Answer for the selected question. Formulas render as mathematics when the file is marked as containing them, and figures stored next to the file are shown inline.

Habit tracker

A habit is something you record repeatedly for a period, and the period needs a verdict: did I make it this week? The tracker stores one habit with a cycle (daily, weekly, monthly or whole period), a start date and an optional end date, one or more items you log against (each with its own properties), and criteria that decide when a day counts and when the whole cycle passes.

Create a habit from a template

New Habit opens a wizard with five steps — Template → Basics → Items → Targets → Preview.

  • Pick a template, or Custom to start from an empty habit.
  • The template fills in the name, the cycle, the items and properties, and the goal. Everything stays editable: rename the items, change a property's type, add a fifth exercise, set your own target. Nothing about a template locks the habit.
  • Items is where you add or rename what you log. A property is yes/no, a number, or a list (free-text entries, optionally unique per day or per cycle).
  • Targets is the goal itself. Depending on the root criterion you set either a cycle target ("this many successful days in the week") or a threshold ("this many kilometres in the week").
  • Preview simulates a period from the punches you would plausibly record, so you can see the progress bar and the verdict before you commit. The simulation is approximate for exotic setups; the real calculation happens on the server.

Re-picking a template while you have edited something asks for confirmation first: it replaces your items and criteria.

Names you type for items and properties become part of the habit, so a habit created while the interface is in Chinese carries Chinese item names — and vice versa.

Punching

Punch on a card (or on the habit's page) opens one session. Each item is a panel of its own, and the control depends on the property's type:

  • Yes/no — tick it and it saves immediately. One value per property per item per day; a second tick the same day replaces the first.
  • Number — enter an amount; each submission is added to the day's and the cycle's running total, so three short runs add up. You can log the same item several times a day.
  • List — one entry per line. Entries are appended, and if the property is marked unique per day an entry you already recorded that day is rejected. A rejected entry discards that item's whole record for the session and names the offending lines; other items in the same session are saved anyway, and the message tells you which ones failed.

About dates, which is where people get surprised:

  • New punches may be dated today or any earlier day inside the habit's window, never a future day, and never before the start date. The dialog spells out the punchable range under the picker.
  • Once a session has recorded something, its date locks for the rest of that session: items you tick afterwards are stamped with the date you started with, because silently moving them would mislabel them. Close the dialog and open it again for another day.
  • A stored punch keeps its date forever. To move a record, delete it in the punch history and punch the right day. Editing the values of a past punch is always allowed — even after the period has ended or the habit was deactivated — and the day, the cycle and the history are recomputed from the stored punches, so a correction shows up everywhere at once.
  • Days are counted in the server's timezone, so "today" can differ from your local midnight if you travel.

Progress, calendar, editing

Habit cards show a progress bar for the current cycle, the root goal as current / target, and a red passed mark when the cycle is satisfied; daily habits also show today's own value. Edit reopens the wizard on the same habit. The menu on each card holds Shares…, Deactivate and Delete.

The Calendar page plots punches over a month, a week or a single day, so you can see the shape of a month at a glance rather than reading bars.

Deactivate makes a habit read-only for good — history stays, no new punches, no reactivation, which is why it asks for confirmation. Delete removes the habit with its items, criteria and entire punch history, and is refused once the habit has been shared with somebody.

Sharing a habit

Shares… on a habit card lets you invite a named user (search by display name; the app only sees the name and an id, never an email address). The invitation takes effect immediately and can be revoked immediately. What the invited person gets is the Shared with me page: a read-only view of that habit and its full punch history, credited to its owner, with every write affordance removed — they cannot punch, edit, share or delete it, and they cannot see who else it was shared with. Sharing does not transfer ownership, and a second invitation to the same person is a no-op.

Account, language and ratings

Signing in

The right end of the navigation bar holds Sign in, and once you are in, your name with a menu for My account and Sign out. Your account page lists the days you have signed in over the last quarter, which is a cheap way to watch your own consistency.

The identity provider is the same account service behind the other pages on this site. If a sign-in fails or the connection is lost, a bar appears under the navigation with a retry; you can dismiss it.

The invitation code, and what needs one

The shield button opens a small dialog for an invitation code. Only the AI features ask for it — the "Explain" and chat helpers on the sentence pages and the generated quizzes on the formula page. Everything described above — vocabulary review, spelling, dictation, quizzes you assemble yourself, worksheets, Chinese and Knowledge Bank printing, the whole habit tracker — runs without a code. Audio uses your browser's speech engine when no recording exists, so it is also free.

Signing out clears the code, along with the cached habits and ratings.

Language

The language control switches the interface between English and 中文, and the choice is remembered for the next visit. This page follows it too — the guide you are reading is the document that belongs to your language.

Exercise content itself is not translated: a word file's Chinese column and an English column are data that came with the file, not interface text.

Where your data goes

Ratings, habits, punches and sign-in days are stored per user on the learning API, and nothing is anonymous: another user cannot see them, not even by guessing an id — with the single exception of the habits you deliberately share. Clearing the browser's storage changes nothing about them; the records live server-side, which is why you can sign in from another machine and continue the same habit.
